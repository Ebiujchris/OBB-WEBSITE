# Obudhingiya Bwa Bwamba Website

A Next.js website preserving the cultural heritage, languages, and traditions of the Bwamba people.

## Color Palette

- **Burgundy** (#6B1E2E) - Primary/Royal feel
- **Gold** (#C99A2E) - Accents, buttons, highlights
- **Forest Green** (#1F4D3A) - Secondary/Nature & heritage
- **Ivory** (#F8F3E7) - Main background
- **Charcoal** (#242424) - Text
- **Earth Brown** (#7A5C3E) - Secondary backgrounds

## Getting Started

Install dependencies:
```bash
npm install
```

Run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Tech Stack

- Next.js 14+ with App Router
- TypeScript
- Tailwind CSS v4
- React

## Structure

- `/app` - Pages and layouts
- `/components` - Reusable components
- `/public` - Static assets

## Features

- Three languages: Lubwisi, Lwamba, Luvanuma
- Cultural content: Stories, Proverbs, Riddles, Songs, Poems, Lullabies, Names
- News and Events
- Contact form
- Responsive design
